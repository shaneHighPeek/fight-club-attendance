# Branding

## Theme

- **Theme**: Dark
- **Primary accent (red)**: `#C80F12`
- **Dark gray**: `#202020`
- **Neutrals**:
  - `#FFFFFF` (text on dark)
  - `#0B0B0B` (page background suggestion)
  - `#121212` (surface/cards suggestion)

## Typography

- **Headlines**: Oswald Bold
- **Body**: Open Sans Regular

## Logo

- **Primary logo file**: `navigationlogo.png`
- **Usage guidance**:
  - Prefer the logo on dark backgrounds for maximum contrast.
  - Maintain clear space around the logo (at least the height of the inner text).
  - Do not recolor the logo; use as-provided.

## UI Notes (Kiosk)

- High contrast and large tap targets.
- Avoid subtle grays for critical actions; use `#C80F12` for primary CTAs.
- Keep kiosk UI uncluttered: 1 primary action per screen.
