# Web App

Frontend app for kiosk and admin interfaces.

## Scripts

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run preview`

## Notes

- Built with React + TypeScript + Vite.
- Firebase Hosting serves `web/dist` in this repository.
- Route structure and implementation plan are defined in `docs/implementation-plan-v1.md`.
